<evidence>
**1. `07-04-02-SUMMARY.md` is the probe playbook, and it cost three deviations
to write.** Read its "Deviations" section before starting. What it establishes:

- **Show the console for real, do not render it offscreen.** A `ContextMenu`
  and a `ComboBox` drop-down are `Popup`s - separate top-level windows - so
  `PrintWindow` on the console and `RenderTargetBitmap` on its content both
  photograph a closed list. 07-04-02 showed the window and took a screen
  capture of the region for exactly this. A drop-down is the same problem.
- **`RenderOptions.ProcessRenderMode = 'SoftwareOnly'`** in the probe:
  hardware rendering on this host paints blank often enough to look like a
  wiring failure.
- **Never `ShowDialog` a nested modal from the thread already in control** -
  it deadlocks. `EventManager.RegisterClassHandler` on `Window.Loaded` killed
  the probe process outright; a `DispatcherTimer` never found a modal that was
  demonstrably open for 90 seconds.
- **A native modal is driven from a genuinely separate runspace**:
  `[runspacefactory]::CreateRunspace()`, STA, find the window by title, and
  `SendMessage` / `BM_CLICK`. That is how the `Remove Media` `MessageBox` was
  answered, and it is how this plan's `SaveFileDialog` gets cancelled.
- **Crop to the console's own bounds**, so no unrelated window of the user's
  appears in a committed picture.

**2. Probe the console with a clean `PSModulePath`.** A pwsh 7 parent poisons a
5.1 child and every HDT window dies before it draws. Start the probe as
`powershell.exe -STA -NoProfile -File <probe.ps1>` with `PSModulePath` unset,
from Bash.

**3. The share is read-only to this plan.** `C:\HDTLab\Share` is on
PROJECT.md's never-delete list, and it holds real media definitions
(`HYDRATION-USB`, `WIN11-FIELD`, `HYDRA` at last count). The probe **opens
lists and closes them**; it picks nothing. A `ComboBox` raises
`SelectionChanged` on a PICK, not on being opened, so an opened-and-escaped
list commits nothing - but prove it with hashes rather than trusting the
reasoning.

**4. The `SaveFileDialog` must be cancelled, never confirmed.** Confirming it
would write an `output:` key to a real media document on the lab share. Cancel
is also the interesting half: the phase brief's rule is that Browse must not
force a value, and a cancelled picker leaving the box unchanged is that rule
photographed.

**5. Scratch files go in the scratchpad**, not the repo:
`C:\Users\Itamartz\AppData\Local\Temp\claude\C--Users-Itamartz-Documents-GithubRepos-HDT\<session>\scratchpad`.

the probe and the gate run. Never silence.
