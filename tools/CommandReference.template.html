Every public command in the Hephaestus module

HDT rebuilds MDT's operational model — deployment share, task sequences, driver store, application catalog — on PowerShell instead of VBScript. These are the commands the module exports: the ones you type, and the ones the WinPE payload calls on a booted machine.

What a window needs to draw itself is not on this list. The console's view-model builders and the wizard's page helpers are internal to the module, so everything here is something somebody runs.

Each entry shows what the command is for, its parameter sets exactly as PowerShell reports them, every parameter, the examples from its help, and the file it lives in. How it works opens the long-form design note the author wrote next to the code.
